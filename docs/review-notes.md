# 提审备注模板

提交审核时，把下面内容填到「功能页面 / 测试账号 / 补充说明」里。审核员看不到你的代码，这些说明直接影响通过率。

## 功能说明

> 秒见课表是一款无广告的课程表工具。用户可以手动添加课程，查看周课表、今日课程和下一节课。课表数据默认只保存在用户手机本地，支持 JSON / CSV / ICS 文件的导入导出。
>
> 首页提供公告入口，用于展示产品更新和使用提示，支持历史公告和详情查看。
>
> 可选功能「从教务系统导入」需要用户输入本人所在学校的教务账号，登录学校教务系统后拉取课表。该功能不是使用本小程序的前提，用户也可以完全手动录入。

## 测试路径

> 1. 首页 → 点击空白格子，可手动添加课程
> 2. 「今日」页查看下一节课和倒计时
> 3. 「我的 → 学期与节次设置」设置开学日期、总周数、节次时间
> 4. 首页右上角铃铛查看公告列表与详情
> 5. 「我的 → 导入课表 / 导出课表」测试 JSON、CSV、ICS 文件
> 6. 「我的 → 偏好设置」切换默认打开页面，冷启动验证
> 7. 「我的 → 隐私说明与开源声明」查看数据处理说明

## 关于教务导入

> 该功能需要用户所在学校的教务系统账号，审核人员不便测试，可跳过，不影响其他功能的体验。
>
> 使用前页面会要求用户勾选「我确认使用本人的教务账号」，并在导入页明确提示：
> - 仅登录本人所在学校的教务系统
> - 密码在手机上用学校公钥加密后发送，云函数只转发密文
> - 本小程序与学校官方无关
>
> 云函数会在本次登录会话中向学校取回公钥并交给手机；密码在用户手机上用该公钥加密后，云函数只把密文转发给学校，不接触明文，不写入数据库、不写入日志。详细说明见小程序内「我的 → 隐私说明与开源声明」。
>
> 如果审核认为该功能存在风险，我们可以按贵方要求隐藏「从教务系统导入」入口，仅保留手动录入和 JSON / CSV / ICS 导入导出。

## 隐私与数据

> - 课表、学期设置：保存在用户手机本地
> - 学号、密码：仅在导入时使用；密码在手机上加密后只发送密文，不持久化保存；用户主动勾选「记住密码」时才会明文保存在本机
> - 学校列表：云数据库中仅存公开的学校名称和教务地址，不含个人信息
> - 微信 openid：用于校验公告管理员身份、按用户去重统计公告浏览量，不含昵称、头像、手机号
> - 无广告、无第三方统计 SDK、不出售用户数据

## 类目建议

> 工具 > 效率

不要选教育类目：个人主体通常需要额外资质，而且「课程表工具」本身属于效率工具。
