# 用户隐私保护指引填写参考

位置：微信公众平台 → 设置 → 服务内容声明 → 用户隐私保护指引。

按后台实际提示填写，下面是可以直接参考的表述。

## 开发者处理的信息

| 信息类型 | 用途 | 处理方式 |
|---|---|---|
| 学号 / 教务账号 | 登录用户本人所在学校的教务系统，获取课表 | 仅导入时使用，不存储 |
| 教务密码 | 登录教务系统 | 仅导入时使用；云函数在登录会话中取回学校公钥并交给手机，密码在手机上加密后发送，云函数只转发密文，不写入数据库和日志；用户主动勾选「记住密码」时明文保存在本机 |
| 课程信息（课程名、教师、地点、节次、周次、备注） | 展示课表、导出/导入课表备份 | 保存在用户手机本地 |
| 微信 openid | 校验公告管理员身份；按用户去重统计公告浏览量 | 保存在云数据库浏览记录中，不含昵称、头像、手机号 |
| 剪贴板内容 | 导出 / 导入课表文件备份；复制公告中的交流群号 | 仅在用户点击对应按钮时读写 |

## 第三方共享

- 用户填写的学校教务系统：仅用于完成登录和课表查询
- 微信云开发（腾讯云）：承载云函数，转发登录请求，不持久化账号密码
- 不向广告平台、数据分析平台共享任何信息

## 存储期限

- 课表与设置：保存在本机，用户可随时清空或删除小程序
- 账号密码：不存储；用户勾选「记住密码」时保存在本机，取消勾选或重新导入后清除
- 云函数日志：仅保留错误码和错误描述，不含账号密码，按云开发默认策略保留

## 用户权利

- 查看、导出、清空课表
- 取消记住密码
- 删除小程序以清除本机数据

## 联系方式

建议在小程序后台开启「客服」功能，并在隐私说明页保留「通过小程序客服留言」的表述。如果没有客服能力，替换成真实可用的邮箱。

## 与页面内容保持一致

小程序内 `pages/privacy/privacy` 的文案要与后台填写的指引保持一致，避免审核时被认定为「声明与实际不符」。
