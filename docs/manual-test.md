# 真机回归清单（iOS + Android）

自动化测试覆盖不到真机渲染和系统权限，这一份需要人工在手机上走。建议用**体验版**，两台设备各跑一遍。

## 准备

- 体验版版本号：`1.3.0`
- 设备：一台 iPhone、一台 Android
- 测试前先在小程序右上角「···」→「设置」→「清除缓存」，模拟新用户

## 用例

| # | 用例 | 操作 | 预期 |
|---|---|---|---|
| 1 | 首次引导 | 清缓存后首次打开 | 首页显示「欢迎使用秒见课表」三步引导 |
| 2 | 引导跳转 | 点「先设置学期」 | 进入学期设置页，能选开始日期 |
| 3 | 引导消失 | 设置日期并保存返回 | 引导卡消失，周次按设置计算 |
| 4 | 跳过引导 | 另一次清缓存后点「跳过」 | 引导消失，出现「未设置学期」提示条 |
| 5 | 手动添加 | 点空白格子 → 填课程名/星期/节次/周次 → 保存 | 课程块出现在正确位置 |
| 6 | 编辑/删除 | 点课程块 → 编辑 → 删除 | 修改生效，删除后消失 |
| 7 | 周切换 | 左右滑动、顶部切周 | 课程按周次和单双周显示 |
| 8 | 冲突课程 | 同一天同节添加两门课 | 左右并排，不重叠 |
| 9 | 输入框 | 导入页、编辑页不聚焦 | 占位文字完整显示，不裁切 |
| 10 | 学校搜索 | 搜学校简称、中文名或域名 | 都能命中对应学校 |
| 11 | 导入确认 | 不勾「本人账号」直接点导入 | 被拦下并提示 |
| 12 | 教务导入 | 勾选后用测试账号导入课表 | 课程写入，返回首页可见；不再提示「账号或密码错误」 |
| 13 | 今日页 | 查看下一节课、倒计时 | 时间与节次设置一致 |
| 14 | 导出/导入 | 导出 JSON，清空课表，再从剪贴板导入 | 课程和设置恢复 |
| 15 | 隐私页 | 我的 → 隐私说明与开源声明 | 页面完整可滚动 |
| 16 | 客服入口 | 我的 → 问题反馈 | 打开客服会话（需后台已开启客服） |
| 17 | 小屏适配 | iPhone SE 等小屏 | 课表不横向溢出，按钮可点 |
| 18 | 冷启动 | 杀掉小程序后重新打开 | 直接显示课表，无长时间白屏 |
| 19 | 网格对齐 | 添加跨 2–4 节的课程，看块上下边与网格线 | 上下边与网格线对齐，滚动多行也不累积偏移 |
| 20 | 管理员入口 | 我的 → 长按「隐私说明与开源声明」 | 进入管理员页；公告/学校两个权限显示「正常」，底部可刷新；非管理员显示无权限和 openid |
| 21 | 学校管理 | 管理员页 → 学校管理 → 新增一所学校，打开「开放自动导入」 | 保存成功，列表出现新学校 |
| 22 | 新学校生效 | 等 1 分钟，重新打开学校选择页或下拉刷新 | 新学校显示「安全导入」 |
| 23 | 关闭自动导入 | 编辑学校，关闭「开放自动导入」并保存 | 学校选择页显示「仅手动」，导入入口被拦下 |
| 24 | 慢速拖拽切周 | 在课表上把手指**慢慢**拖动 3–5 秒 | 跟手不卡顿；到第 1/最后一周时有阻尼回弹 |
| 25 | 首次学校列表 | 清除缓存后进入选择学校 | 先显示「正在加载学校列表…」，然后一次性出现全部学校，不闪 |
| 26 | 快速连滑 | 连续快速轻扫两次 | 前进两周，不会吞掉第二次；轻扫短距离也能翻页 |

## 已知限制

- 教务导入依赖学校系统，若学校启用验证码或限制校外访问，会失败
- 「记住密码」会把密码明文存在本机，建议不勾选
