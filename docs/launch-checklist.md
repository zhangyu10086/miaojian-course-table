# 公开上架清单

## 今天：启动最长链路

### 1. ICP 备案

路径：微信公众平台 → 设置 → 基本设置 → 小程序备案。

准备：

- 主体负责人身份证正反面
- 手机号、邮箱
- 应急联系人信息
- 服务内容说明，可填：`提供课程表查看与管理工具，不提供教育教学服务`
- 在线签署承诺书

流程：平台初审 → 工信部短信核验 → 管局审核。通常 1–20 个工作日。**备案不影响开发和使用体验版。**

### 2. 服务类目

路径：设置 → 基本设置 → 服务类目。

选 **工具 > 效率**。不要选教育类，个人主体通常需要办学资质。

### 3. 基本信息

- 名称：秒见课表
- 简介：秒开秒见（8 字）
- 头像：`秒见课表logo-144.png`

## 提审前

- [ ] 重新编译，真机走一遍完整流程
- [ ] 确认页面上没有「体验版」「自用」等字样
- [ ] 隐私说明页可以正常打开
- [ ] 教务导入页有风险提示和「本人账号」勾选
- [ ] 空课表状态有引导，不会让审核员以为功能坏了
- [ ] 上传代码，版本号 `1.0.1`
- [ ] 填写提审备注，参考 `docs/review-notes.md`
- [ ] 在公众平台填写用户隐私保护指引，参考 `docs/privacy-declaration.md`

## 可能被拒的原因与应对

| 拒绝原因 | 应对 |
|---|---|
| 类目不符 | 改成「工具 > 效率」，说明是效率工具 |
| 涉及第三方账号密码 | 强调仅限本人账号、无需登录即可使用主要功能；必要时隐藏导入入口 |
| 功能无法体验 | 补充测试路径，说明手动录入即可完整体验 |
| 隐私声明不符 | 对齐页面文案与后台指引 |
| 名称侵权 | 准备备用名，修改名称有次数限制 |
