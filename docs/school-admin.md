# 学校管理（管理员）

1.3.0 起，新增学校不再需要改代码、上传小程序或等审核。学校数据直接写云数据库，约 1 分钟生效。

## 一次性准备

1. 部署 `manageSchool` 云函数
   - 右键 `cloudfunctions/manageSchool` → 上传并部署：云端安装依赖
2. 重新部署 `listSchools` 和 `syncSchedule`
   - `listSchools` 需要返回 `autoImport`
   - `syncSchedule` 需要按 `autoImport` 决定是否允许访问
3. 给 `manageSchool` 配置环境变量 `ADMIN_OPENIDS`
   - 值和管理公告用的 `publishNotice`、`manageNotice` 一致
   - 微信云开发的环境变量**按云函数单独配置**，不会自动共享
4. 上传 1.3.0 小程序

## 入口

「我的」→ **长按「隐私说明与开源声明」** → 管理员页 →「学校管理」。

管理员页会同时检查 `publishNotice` 和 `manageSchool` 两个云函数，分别显示「正常」或「未配置」；页面底部的「刷新管理员状态」会重新检查。两个云函数都使用同一个 `ADMIN_OPENIDS`。

学校管理页每个操作都会再经过 `manageSchool` 的 `ADMIN_OPENIDS` 校验，前端隐藏不是唯一保护。

## 新增学校

> 添加前可以先在 Claude Code 里运行 `/school-check 学校名 地址`，它会自动探测教务入口、跑连通性测试，并输出下面三栏该填什么。

1. 点「新增学校」
2. 填写：
   - 学校名称：如 `XX大学`
   - 教务地址：如 `https://jwglxt.wuit.cn`（填首页即可，会自动补 `/jwglxt`）
   - 搜索别名：如 `wuit, wcgxy, wuchanggongxueyuan`，逗号分隔
3. 打开「开放自动导入」
4. 保存

保存后：

- 云数据库 `schools` 立即有新记录
- `syncSchedule` 的域名缓存 60 秒，最多 1 分钟后允许访问
- 用户重新打开学校选择页，或下拉刷新，就能看到新学校
- 用真实账号导入一次；成功后 `syncSchedule` 会自动把 `verified` 改成 `true`

## 编辑与删除

- 编辑：可以改名称、地址、别名，以及「开放自动导入 / 已实测通过」两个开关
- 删除：只删除学校记录，不会删除用户已经导入的课程
- 删除后，已经停留在旧页面的用户可能还能看到缓存，重新打开学校列表即可

## autoImport 的三种状态

| 值 | 小程序显示 | 说明 |
|---|---|---|
| `true` | 安全导入 | 开放自动导入 |
| `false` | 仅手动 | 明确关闭，云函数也会拒绝 |
| 缺失 / `null` | 按本地白名单 | 旧数据兼容；`secure-import.js` 里的 12 所仍可导入 |

建议：以后新增学校都明确设置 `autoImport`。旧学校不用批量迁移，编辑保存一次就会写入明确值。

## 常见问题

**加了学校，但用户看不到**
- 确认「开放自动导入」已打开
- 等 1 分钟（云函数缓存）
- 让用户重新打开学校选择页，或下拉刷新

**用户选了学校，但页面显示「仅手动」**
- 检查 `autoImport` 是否为 `false` 或缺失
- 缺失时只有内置白名单里的学校会被当成可导入
- 编辑这所学校，打开「开放自动导入」并保存

**进入学校管理提示无权限**
- 确认 `manageSchool` 配置了 `ADMIN_OPENIDS`
- 环境变量是按云函数配置的，不能只在 `publishNotice` 里配
- 页面会显示当前 openid，复制后填进去，保存再重试

**保存提示「这个教务地址已经添加过了」**
- 同一个 `host` 只能有一条记录
- 直接编辑已有学校，不要重复新增

**保存提示「请填写公网可访问的教务地址」**
- 拒绝了 localhost、内网 IP、`.local`
- 学校只能通过校园网/VPN 访问时，云函数也连不上，不能自动导入

## 为什么不用发版

以前的支持学校名单写在 `miniprogram/utils/secure-import.js`，是客户端代码，改一次就要发一次版。

现在名单以云数据库的 `autoImport` 为准，`secure-import.js` 只作为旧数据/离线时的兜底。加学校只是写一条数据库记录，所以不需要审核。

## 仍然需要发版的情况

- 教务系统登录流程改版（接口路径、字段变化）
- 新版正方之外的新系统（如强智、URP）
- 小程序界面或交互调整
