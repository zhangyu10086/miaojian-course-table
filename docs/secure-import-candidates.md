# 可加入自动导入白名单的候选学校

> 2026-10 更新：公钥和登录现在都由云函数完成，**不再要求学校域名能加入小程序 request 合法域名**。白名单只表示「已开放自动导入、等待实测」。

云函数访问学校的限制是：

- 学校必须能被公网访问，不能只允许校园网/VPN
- 必须支持新版正方 `jwglxt` 登录流程
- 登录页不能强制验证码/滑块
- 登录页要有 `csrftoken`，公钥接口要返回 `modulus`/`exponent`

学校按会话轮换公钥（例如示例学校）已经由 `prepare` 流程处理，不再是问题。

## 新增一所学校的步骤

1. 先用不存在的账号跑一次导入（或用云函数日志确认），能返回「账号或密码错误」说明链路通了。
   - 如果返回网络错误、登录页结构错误、验证码，先不要开放
2. 打开小程序「我的 → 长按隐私说明与开源声明 → 学校管理」，新增这所学校
3. 打开「开放自动导入」，保存，等约 1 分钟
4. 用该校真实账号实测导入
5. 导入成功后，云函数会自动把 `verified` 标成 `true`

1.3.0 起不再需要改 `secure-import.js`、上传小程序或审核，详见 `docs/school-admin.md`。

## 为什么其他学校没进候选

当前学校库里还有一些地址是：

- 只允许校园网 / VPN 访问
- 使用 SSO、统一身份认证，不是正方账号密码登录
- 没有新版正方 `jwglxt` 登录流程

这些学校只能手动添加课程。

## 注意

- 不要一次性把所有候选都开放，先测通再加
- `secure-import.js` 现在只是旧数据/离线的兜底，新学校以数据库 `autoImport` 为准
- 如果学校连不上或需要验证码，导入会提示手动添加，不会发送明文密码
- 白名单只是产品层面的开关，不再涉及公众平台域名配置
